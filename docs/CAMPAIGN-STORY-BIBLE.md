# Campaign story bible — the owner's 31-scene spine

Converted verbatim from `Squatch_Smash_Campaign_Story_Bible2.xlsx`, delivered
2026-08-26. This is the source of truth for campaign order, scene transitions,
continuity state, and the decisions the owner has already made. Where it
disagrees with `docs/CAMPAIGN-TIMELINE.md`, this file wins; the timeline is the
record of what is currently *built*.

The spreadsheet numbers 30 scenes, #0–#29. THE TAKE is the thirty-first: a
shipped, playable mission with no slot in the spreadsheet. The owner placed it
between scene 11 and scene 12 — see **Decisions taken** at the end.

## Campaign principles

| Principle | What it means | Design check |
|---|---|---|
| **Status Ladder** | Nobody → useful Prospect → trusted associate → inner-circle operator → war-tested → made member | Does each chapter visibly change how the family treats the player? |
| **Home Ladder** | Starter apartment → cabin hideout → starter return → luxury apartment → mansion guest → initiation cabin | Does each location reflect current status? |
| **Margo Arc** | Meet/get number → cabin call → Front & Center date → stayover → morning exit | No extra date mission needed. |
| **Sasole Arc** | Meet via Beef Run → flight tutorial → Enola payoff | Enola must remember Beef Run. |
| **War Arc** | Silver Case → Mansion → Siege → Enola → repaired Mansion → Palace → initiation approval | Every mission must cause the next one. |
