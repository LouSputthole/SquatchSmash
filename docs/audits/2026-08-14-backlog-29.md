## 1. Silver Pines' whole conversation tree is silent over recordings that exist

## 2. Promote the Silver Room's settings model into a shared core settings module
`src/silver/main.js:188-215` already has a complete, persisted accessibility model — `subtitles`, `bigSubtitles`, `reduceShake`, `assist` on `squatch.*` localStorage keys, applied via `body.nosubs` / `body.bigsubs` (`src/silver/silver.css:296-301`). It exists in exactly **one** of twenty scenes. Extract to `src/core/settings.js`, render it in `src/core/pause-menu.js` (which currently has only Resume + recovery buttons), and the other 19 scenes get subtitle size/off, reduced motion, and assist for free — over 3,216 recorded voice lines currently have no caption control anywhere but the date scene.
