## Deliver it exactly like this

Every file goes in `assets/sfx/` **under the exact filename shown**. Then:

```
npm run sfx:listen      # rebuild assets/sfx/index.json and audition
npm run voice:needed    # what is left
npm run record:sheet    # regenerate this file
npm test && npm run check
```

A re-record overwrites the file that is already there. Once its replacement is indexed,
delete that line's entry from `assets/sfx/rerecord.json` and run `npm run vo:rerecord`,
or `npm run check` will keep reporting the take as stale.
