# Silver Sasquatches art library

Owner-supplied PNG artwork retained at its original resolution and byte content.
The runtime can load any image directly from:

`assets/art/silver-sasquatches/<filename>`

These files are intentionally not in the wall-art `manifest.json` yet. That
manifest requires a real scene slot; add a row only when a specific image and
placement have been chosen.
